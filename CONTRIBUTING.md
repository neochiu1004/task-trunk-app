# Contributing

Thanks for helping improve Task Trunk App. This project is maintained as a
small, focused PWA for local-first ticket and voucher management.

## Before You Start

- Check existing issues before opening a new one.
- Keep pull requests focused on one problem.
- Prefer small, reviewable changes over large rewrites.
- Include screenshots for visual or mobile layout changes.
- Explain data migration or import/export behavior changes clearly.

## Local Development

```bash
npm install
npm run dev
```

Run checks before opening a pull request:

```bash
npm run lint
npm run build
```

## Good First Issues

Good starter contributions include:

- Fixing typos or unclear documentation.
- Improving accessibility labels and keyboard flows.
- Adding validation for edge cases in ticket import/export.
- Improving empty states or mobile spacing.
- Reproducing barcode scanning issues with sample details.

## Pull Request Guidelines

Please include:

- What changed.
- Why it changed.
- How you tested it.
- Screenshots or screen recordings for UI changes.
- Any known limitations or follow-up work.

## Project Priorities

The project favors:

- Local-first data ownership.
- Predictable import/export behavior.
- Mobile-first interaction design.
- Clear, simple code over clever abstractions.
- Incremental improvements that are easy to review.
