# Support

Task Trunk App is maintained as an open-source project by one primary
maintainer.

## Get Help

- Open a GitHub issue for reproducible bugs.
- Use a feature request issue for workflow suggestions.
- Include browser, device, and reproduction details whenever possible.

## Please Do Not Share Private Data

Tickets, vouchers, serial numbers, QR codes, and redemption links can contain
private or valuable information. Please redact sensitive data before attaching
screenshots or sample files.
