# Roadmap

This roadmap describes the current maintenance direction for Task Trunk App.
Items may change as users report real workflows and edge cases.

## Near Term

- Improve backup import validation and make error messages easier to act on.
- Add clearer empty states for first-time users.
- Improve barcode selection when an uploaded image contains multiple codes.
- Add lightweight tests around data helpers and validation logic.
- Document common ticket and voucher workflows with examples.

## Medium Term

- Add release notes for user-facing changes.
- Improve accessibility for dialogs, drawers, and batch actions.
- Add optional encrypted backup exploration.
- Improve PWA offline behavior and cache update messaging.
- Add more template presets for common voucher formats.

## Long Term

- Explore optional sync while preserving local-first data ownership.
- Add import adapters for common exported ticket formats.
- Improve contributor onboarding with architecture notes.
- Build a small public feedback loop around issues and discussions.

## Non-Goals

- Storing user ticket data on a required hosted backend.
- Replacing official ticketing platforms.
- Adding tracking or analytics that compromise user privacy.
